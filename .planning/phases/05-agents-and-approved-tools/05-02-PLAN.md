Use github.com/modelcontextprotocol/go-sdk/mcp with StreamableClientTransport and a pinned maintained version compatible with this Go module; consult its current client/protocol documentation and preserve MIT/Apache notices. Do not use the README stdio/CommandTransport example, register arbitrary executable commands, expose roots, or accept server-initiated model sampling/credential elicitation. Reuse origin/address/redirect validation and shared processing policy for the approved destination; private servers require explicit authorized reachability. Bind HTTP credentials to exact approved origin and current tenant. Bound connection/session lifetime, discovery pages/tools, body/SSE/event bytes, call duration and response content; close sessions/bodies on completion/cancel. Validate call arguments and output against the approved schema, treat tool output as untrusted generated content, and preserve all input restrictions. Do not auto-follow resource links or arbitrary URLs embedded in tool results. Classify known not-dispatched versus possible side effect and expose the latter as unknown without retry; SDK reconnect must not replay a mutation.

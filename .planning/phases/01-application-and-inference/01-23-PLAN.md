  <action>
Use auth.SecretResolver from 01-21 for tenant/purpose/origin-bound credential lookup. Billing uses the core per-unit PriceSnapshot rate set, not one rate for all tokens: parse provider input/output/cached usage into disjoint UnitKind counts, snapshot every required rate, reserve a conservative bound and reject missing-unit prices or currency mismatch. Never silently price cached input twice or treat unrecognized advertised units as free. Include those cases in the existing executor/usage tests.
Load tenant endpoint/config revisions through a narrow service-owned repository interface implemented by postgres; do not import concrete postgres back into inference (postgres already consumes inference.Endpoint). Create/reuse the two existing transport kinds and per-endpoint caches, with deterministic configured route selection; no new provider/plugin framework. Before network dispatch, enforce an operation-specific upper bound and call billing.Reserve with the immutable rational rate/unit snapshot. Text, embedding, vision and Responses/compact operations need a real bounded price/capability rule; refuse unknown/unbounded pricing rather than assume zero. Distinguish never-dispatched failure from potentially accepted work; mark dispatch durably before an ambiguous crash and never hold a DB transaction during network I/O. Preserve usage events across streaming and nonstreaming results, settle exact actual raw units once without clipping, and keep unknown liability if final usage/outcome is unavailable. Close/cancel timers, response bodies and shared attempt state exactly once. A response/stream remains owned by the caller until Close; later admission gates attach to that lifetime. Do not transparently retry or change endpoints after potential acceptance/partial output. Tests cover missing prices, fractional-unit pricing, overflow rejection, duplicate settlement, actual overrun, disconnect with unknown usage and a verified not-dispatched release.

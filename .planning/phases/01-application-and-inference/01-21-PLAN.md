Define a small SecretBinding representation and SecretResolver owned by auth, with opaque reference ID, exact tenant ID, selected integration purpose/source kind, explicitly approved origin set and operator-owned environment source. Config parses/validates these bindings; keep imports acyclic (auth must not import config). Reuse environment-backed secrets already used by the application, not a second vault/backend framework or new public secret-management product. Only trusted runtime configuration supplies environment names. Resolve(tenantID,purpose,origin,refID) checks all bindings before reading/returning a value; duplicates, malformed origins, missing bindings/values and wrong tenant/purpose/origin are explicit sanitized errors. Canonicalize origins using real URL parsing, including scheme/host/port, and reject credentials embedded in URLs. Source adapters may need more than one exact approved API/download/token origin; these are server-controlled, never an arbitrary redirect allowance. Return only safe reference metadata to configuration UIs. Explicitly configured unauthenticated local endpoints send no credential and never inherit a global SDK/environment key by accident. This does not add OAuth-enrollment flows, a credential backend selector or a deployment secret-provisioning program.
